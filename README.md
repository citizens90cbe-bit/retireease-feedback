# RetireEase — Feedback & Support

This is the **public feedback tracker** for [RetireEase](https://retireease.up.railway.app) — an institutional-grade retirement income planner.

Use this repository to:
- 🐛 **Report a bug** — something broken or behaving unexpectedly
- 💡 **Share feedback or a feature idea** — suggest improvements or new capabilities
- ❓ **Ask a question** — anything about how a feature works

---

## How to Submit

Click **[New Issue](https://github.com/citizens90cbe-bit/retireease-feedback/issues/new/choose)** and pick the appropriate template. You will need a free GitHub account.

Before submitting, please check:
1. The **[User Guide](https://retireease.up.railway.app/UserGuide.html)** — your question may already be answered there
2. **[Existing issues](https://github.com/citizens90cbe-bit/retireease-feedback/issues)** — to avoid duplicates

---

## Response Times

| Type | Target response |
|---|---|
| 🐛 Bug (Critical — app broken) | Within 24 hours |
| 🐛 Bug (Non-critical) | Within 72 hours |
| 💡 Feedback / Feature idea | Reviewed weekly |
| ❓ Question | Within 48 hours |
